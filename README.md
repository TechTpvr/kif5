# کیف‌نت v6

نسخه بهبود‌یافته کیف‌نت با تمرکز روی پایداری، بازار و تجربه ورود.

## تغییرات اصلی
- اضافه شدن «نبض بازار» در بخش بازار.
- نمودار سه شاخص: سکه تمام بهار آزادی، طلای ۲۴ عیار و دلار آمریکا.
- بازه‌های لحظه‌ای، هفته، ماه و سال.
- ثبت تاریخچه نرخ‌های دریافتی روی همان دستگاه برای ساخت نمودارها؛ داده ساختگی تولید نمی‌شود.
- کاهش بروزرسانی بازار از هر ۱ ثانیه به هر ۳۰ ثانیه برای جلوگیری از فشار و درخواست‌های غیرضروری.
- اضافه شدن طلای ۲۴ عیار به داده‌های بازار.
- بهبود انیمیشن ورود/لود لوگو با حالت روشن و تاریک.
- اصلاح نوع favicon به PNG.
- نسخه Service Worker به v6 برای جلوگیری از کش شدن نسخه قدیمی.
- خروجی پشتیبان به نسخه v6 ارتقا یافت.

## نکته مهم درباره نمودار تاریخی
بازه‌های هفته/ماه/سال بر اساس تاریخچه‌ای است که کیف‌نت از زمان استفاده و دریافت نرخ‌ها روی دستگاه ثبت می‌کند. چون منبع فعلی پروژه یک API تاریخی کامل ارائه نمی‌کند، برای جلوگیری از نمایش داده جعلی، تاریخچه گذشته از زمان نصب ساخته نمی‌شود.

## احراز هویت
در این نسخه احراز هویت و حساب کاربری/سرور اضافه نشده است و اطلاعات مالی همچنان محلی هستند.
